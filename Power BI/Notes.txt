How to create tooltip :- 
	Step 1: Create the main visual
	Step 2: - Add a new page 
		- Click on the “format” options
		- Go to “Canvas settings”
		- Set the page type as “tooltip” from “16:9”
		- On this “new” page, just add whatever visuals, images & textboxes you want to show .
	Step 3: - Link tooltip page to main visual (Go to Main page)
		- Go to “format” and “general”
		- Select the “tooltip” area.
		- Set the type to “Report page”
		- Select the page from the list of pages.

		Remove ALL filters Ex:- Total Sales (All) =
		CALCULATE(SUM(Sales[Amount]),ALL(Sales)) -- Ignores all filters on Sales table (Useful for calculating % of total) 
	10. ALLEXCEPT() — Remove filters except some columns
