Data Modeling:- 
	1. The Main table, which contains relation between two features called "Fact Table".(Tall and narrow table)
	2. Other tables that give information about a feature called a dimension table. (Short and wide)
	3. Star schema :- In this one center fact table and around dimension table make star schema and this all stuff called as Model .
	4. Snow Flake :- The another table which give info about dimension table not connect to fact table.
	5. Measures :- For calculate some feature (for overall and some group).
	6. Slicer/Filter :- for selection of group and get values only for this group.
	7. ETL (Extract transform load).
	8 Batch process :- The process run at specific time when some condition is made called batch process.

How to create tooltip :- 
	Step 1: Create the main visual
	Step 2: - Add a new page 
		- Click on the “format” options
		- Go to “Canvas settings”
		- Set the page type as “tooltip” from “16:9”
		- On this “new” page, just add whatever visuals, images & textboxes you want to show .
	Step 3: - Link tooltip page to main visual (Go to Main page)
		- Go to “format” and “general”
		- Select the “tooltip” area.
		- Set the type to “Report page”
		- Select the page from the list of pages.
	Done !!
