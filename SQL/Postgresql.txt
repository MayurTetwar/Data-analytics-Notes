	6.1.GROUP BY :
		The GROUP BY statement group rows that have the same values into summary rows.
		It is often used with aggregate functions (COUNT(), MAX(), MIN(), SUM(), AVG()) to group the result-set by one or more columns 
		• Example.: SELECT mode, SUM(amount) AS total
			    FROM payment
			    GROUP BY mode;

							(here if p_name is null them return 'Total'))
			sum(total_price)
			from billing_info GROUP BY rollup(p_name)
			order by sum(total_price);

	7.HAVING clause: 
		The HAVING clause is used to apply a filter on the result of GROUP BY based on the specified condition.
 		The WHERE clause places conditions on the selected columns, whereas the HAVING clause places conditions on groups created by the 		GROUP BY clause
		 • Example.: SELECT mode, COUNT(amount) AS total 
			    FROM payment GROUP BY mode
 			    HAVING COUNT(amount) >= 3
			    ORDER BY total DESC;

	8.JOIN: 
		JOIN operation is used to combine rows from two or more tables based on a related column between them.
		TYPES:	
		Note:- Natural join without using key (it used similar named column as key)
			1.CROSSE JOIN:- Every row from one table is combined with every row from another table.(NOT IMP)
			2.INNER JOIN:- note:- you can use INNER JOIN or JOIN.
				       Returns only the rows where there is a match between the specified columns in both 
				       the left (or first) and right (or second) tables.(like union(similar part) of two tables)
				       Ex:- 1.select * from customers c INNER JOIN orders o ON c.cust_id=o.cust_id;
					    2.select c.cust_name,sum(o.price) as Total,count(c.cust_id) from customers c INNER JOIN orders o
					      on c.cust_id=o.cust_id group by c.cust_name;	
			3.LEFT JOIN:- Returns all rows from the left (or first) table and the matching rows from the right (or second) table.
				      Ex:- 1.select * from customers c LEFT JOIN orders o ON c.cust_id=o.cust_id;
					   2.select c.cust_name,sum(o.price) from customers c LEFT JOIN orders o 
					     ON c.cust_id=o.cust_id GROUP BY c.cust_name having sum(o.price)!=0;
			4.RIGHT JOIN:- Returns all rows from the right (or second) table and the matching rows from the left (or first) table.
			5.Full OUTER JOIN:- Returns all records when there is a match in either left or right table.		
					    (return mathching rows and an mathchhing with null values).
					    Ex.: SELECT * FROM customers c FULL OUTER JOIN orders o ON o.cust_id = c.cust_id;
			6.SELF JOIN:- SELF Joins are powerful for comparing values in a column of rows with the same table.
				      Ex.:- select * from emp e1 JOIN emp e2 ON e2.emp_id = e1.manager_id;

	14. Window Function: 
			     this applies aggregate, ranking and analytic functions over a particular window (set of rows). 
		             And 'OVER' clause is used with window functions to define that window.
		  Syntax:- SELECT column_name(s), fun() OVER  ( [ <PARTITION BY Clause> ],
 								[ <ORDER BY Clause>     ],
 								[ <ROW or RANGE Clause> ] )

			 1. Select a function :- • Aggregate functions			
 						 • Ranking functions (Analytic numbering functions)		
 						 • Analytic functions (Analytic navigation functions)

			 2. Define a Window :- • PARTITION BY -> asign same value(calculated) to all partition row (similar to group by but not do 								grouping)
					       • ORDER BY -> used to calculate running values in perticular order (First order by then sum from 								first row)
					       • ROWS -> range from cureent row to upper and lower rows 
							 (ROWS BETWEEN UNBOUNDED(n)(uper ke rows ka number) PRECEDING AND UNBOUNDED(n)(niche wale 								rows) FOLLOWING) 

			 3. Ranking :- • ROW_NUMBER() :- Direct counting of rows from up to down.
				       • RANK() :- Give rank to each value if repeted then same and skip the next value 
						Ex.:- 1,2,2,4,5,6,6,8
				       • DENSE_RANK() :- Give rank to ach value if repeted then same without skip 
						Ex.:- 1,2,2,3,4,5,5,6
				       • PERCENT_RANK()	:- Give rank percentage which express that how many percentage of rows 
				       • NTILE(n) :- divides rows into n buckets
			 
			 4. Analytic functions:- • FIRST_VALUE(column):- first value in window frame
 						 • LAST_VALUE(column):- last value in window frame
 						 • LEAD(column,offset):- This return next value of this column else NULL
 						 • LAG(column,offset):- This return previous value of this column else NULL
		
		Ex.:- 1. Aggregate functions:- select emp_id,dept, count(emp_id) over (PARTITION BY dept order by emp_id) as "emp_count" from 							employee;
		      2. Ranking functions:- select fname,dense_rank() over(order by salary desc) from employee;
		      3. Analytic functions:- select dept,
						first_value(dept) over(order by dept) as "FIRST_VALUE",
						last_value(dept) over(order by dept) as "LAST_VALUE",
						lead(dept,2) over(order by dept) as "LEAD",
						lag(dept,2) over(order by dept) as "LAG"
						from employee;

	15. CTE:- CTE (Common Table Expression) is a temporary result set that you can define within a query to simplify complex SQL statements
		  In journal cases, cte is used with joins to solve the problem. 
		  Ex.:-
			with max_sal as (
				select dept,max(salary) as max_salary from employee group by dept
			)

			select 
				e.fname,e.dept,e.salary
			from employee e join max_sal m
			on e.dept=m.dept
			where e.salary=m.max_salary;
